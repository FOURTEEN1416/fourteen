### W-B 小凌公式 × 学术文献对照批判（与 W-A 并行 · 强推荐）

**动机**：小凌的公式是作者手写稿、未经学术验证（基线①已声明只能当灵感）。深化=**拿原始文献逐一对照，指出哪些是学术共识、哪些是作者自由发挥、哪些可能错了**，给出修订建议。

- 对照清单（公式 → 文献方向）：
  - 艾宾浩斯 `D(t)=D0·exp(-λt)` 与"意义/细节分离衰减"→ 记忆巩固与系统巩固文献（consolidation / systems consolidation）；Power forgetting law（幂律 vs 指数的百年之争）；
  - 巴特利特重构 `Q_recon` → reconstructive memory / false memory 文献；
  - 预测加工 `Disappointment = E×I×|PE⁻|` → prediction error / active inference（Friston 线）；
  - 依恋 `ΔTrust = αP+βC−γV−δB` → attachment theory（Bowlby/Ainsworth）与 trust calibration 文献；
  - 情绪评价理论（Appraisal）→ OCC 模型 / Scherer；Russell 环状模型（jiwen 已在用，可交叉）；
  - 佛教概念工程化（阿赖耶识/末那识）→ 有无先例（意识科学对佛教心理学的研究，如 Lutz/Thompson 线）。
- **检索分域**：学术文献属信息类调研，WebSearch/firecrawl/arxiv 均可（不强制 GitHub）。
- **产出物**：`docs/reports/2026-09-xx_小凌公式学术对照.md`——每条公式给「文献共识 / 作者发挥 / 建议修订」三态结论，供 P4 采用时替换为有出处的版本。
