---

## 1. 因果回放（角色为何说这句）

| 项 | 内容 |
|----|------|
| 输入 | `session_key` + `turn_id` 或 `reply_id` |
| 数据源 | `event_ledger.query/replay` +（P1）prompt_slots 事件 |
| 通过 | 能列出：画像是否注入、记忆条数、关系 level、工具调用与结果、状态增量 |
| 失败样例 | 仅有 assistant_reply、无 slots/profile/tool → **未接线或旁路丢失** |
| 突变 | 清空 prompt_slots 事件 → 探针应 FAIL |

## 2. 双用户串台

| 项 | 内容 |
|----|------|
| 输入 | userA 写入敏感事实（生日/约定）；userB 同文案 turn 标签 |
| 通过 | `ledger.query(userB, turn)` 为空；B 的 profile 投影无 A 字段；回复证据无 A 信息 |
| 失败 | user_key 剥 owner 或历史合并裸形态 |
| 突变 | `user_key_from_session` 去掉 `N:` 前缀 → 必须红 |

## 3. 画像更正

| 项 | 内容 |
|----|------|
| 输入 | 用户原话「我的生日不是 X，是 Y」 |
| 通过 | `user_profile.birthday=Y`；X 清空；ledger `profile_correct`；下一轮 prompt 画像槽为 Y |
| 失败 | 工具失败仍改库；否认后仍保留 X；正则写脏 |
| 突变 | 去掉 `clear_birthday` → 更正探针红 |

## 4. 工具真执行

| 项 | 内容 |
|----|------|
| 输入 | 「明早六点叫我起床」 |
| 通过 | `reminders` 表 `session_key`+`trigger_time` 行；ledger tool_call/tool_result success；到点 delivery 或 status 可查 |
| 失败 | 只有聊天气泡「听到啦」无库行 |
| 突变 | tool_result 恒 success 但 DB 0 行 → 探针以 **DB 行** 判负（骨架注记已写明） |
