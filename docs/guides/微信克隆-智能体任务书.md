# 任务书：导出微信聊天记录 JSON（交给 AI 智能体执行）

> **给谁看**：任何 AI 编码智能体（OpenCode / Claude Code / Cline / Cursor 等）。
> 把本文档整份交给智能体，它即可代替用户完成导出操作。
> **配套工具**：[FOURTEEN1416/wechat-decrypt](https://github.com/FOURTEEN1416/wechat-decrypt)
> **用途**：为「唯一的你」（unique-you）平台的"克隆好友"功能准备聊天记录 JSON。

---

## 1. 你的任务（智能体请先读完本节再动手）

帮用户在其**本地电脑**上，导出微信与**某位指定好友**的聊天记录，产出一份 JSON 文件，供上传到 unique-you 平台做说话风格克隆。

**成功标准**：得到一个可解析、≤50MB、仅含该好友会话的 JSON 文件，并指导用户完成上传。

## 2. 硬性约束（违反即停）

1. **全程只在用户本地电脑操作**——微信数据库解密必须在微信登录的这台机器上进行，服务器无法代劳。
2. **终端必须是管理员权限**（否则读不了微信进程内存）。校验：`whoami /groups` 含 `S-1-16-12288`。
3. **微信必须正在运行，且登录的是要克隆的账号**。没登录就先让用户登录，不要猜。
4. **数据隐私**：聊天记录属敏感数据。除用户主动上传到 unique-you 服务器外，不得以任何形式外传；不在日志/文档里粘贴聊天内容原文。

## 3. 执行路径（按顺序，每步有完成判据）

### 步骤 0：环境自检
- Windows + 微信 4.x 已登录运行；Python ≥ 3.10；终端为管理员。
- 任一不满足 → 停下告知用户如何补齐，不要继续。

### 步骤 1：获取导出工具
```bash
git clone https://github.com/FOURTEEN1416/wechat-decrypt.git
cd wechat-decrypt
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 步骤 2：解密数据库（交给工具仓库自己的智能体手册）
打开并**严格遵循**该仓库的 `AGENTS.md` §0a「冷启动决策树」——它自带从零配置、密钥提取（4.1.9+ 走 Config.Cipher 主路径）、解密的完整判据与排错手册。核心两步：

```bash
python main.py decrypt          # 完成判据: "结果: X 成功, Y 失败, Z 跳过" 且 X>0
```

### 步骤 3：确定目标联系人
- 列出可导出的会话让用户指认（工具仓库 `USAGE.md` §7 有搜索联系人的方法），拿到目标好友的 `wxid` / username。
- **不确定就问用户，禁止猜测**。

### 步骤 4：导出该好友的 JSON
```bash
python export_all_chats.py exported_chats --dry-run --users <wxid>   # 先预览
python export_all_chats.py exported_chats --users <wxid>             # 正式导出
# 可选: --start 2025-01-01 --end 2025-12-31 按日期范围切片
```
完成判据：exit 0 且汇总行 "成功=A 跳过=B 失败=C 总消息=N" 且 A>0。

### 步骤 5：产物校验
- `exported_chats/` 下目标联系人的 `.json` 可被 `json.load` 解析（UTF-8）。
- 数组元素含 `is_self` / `text` / `message_type` 字段（平台原生兼容此格式，另有 `[{user,reply}]` 简单格式可选）。
- 单文件 ≤ **50MB**——超限就按日期范围分片导出成多个文件分别上传。

### 步骤 6：上传到 unique-you
- **推荐（所有用户）**：打开平台控制台 → 创建角色 → 「克隆好友」→ 填被克隆者名称 → 上传该 JSON → 等待服务器分析并预览人设。
- 备选（平台管理员，命令行）：
```bash
curl -X POST "<服务器地址>/api/clone/upload?target=<被克隆者名称>" \
     -H "X-API-Key: <你的APIKey>" -F "file=@exported_chats/<文件>.json"
```

### 步骤 7：收尾报告
向用户报告：导出消息条数、时间范围、JSON 文件路径与大小、上传结果。文件保留与否由用户决定。

## 4. 故障速查

| 症状 | 处置 |
|------|------|
| 密钥提取失败 | 确认管理员终端 + 微信正在运行 + 登录的是目标账号；微信 4.1.9+ 走 Config.Cipher，工具已内置 |
| 解密 N 个全失败 | salt 不匹配（账号换过）→ 重跑密钥提取；详见工具仓库 AGENTS.md §4 排错手册 |
| JSON 中文乱码 | 以 UTF-8 读取；不要用记事本转存 |
| 文件超 50MB | `--start/--end` 按月切片，分多个文件上传 |
| 导出为 0 条 | `--dry-run` 核对 wxid 是否正确；该会话可能无文本消息 |

## 5. 遇到不确定的情况

**问用户，不要猜。** 工具的参数细节以 `--help` 和工具仓库 `README.md` / `USAGE.md` / `AGENTS.md` 为准——它们比本任务书更细，冲突时以工具仓库为准。
