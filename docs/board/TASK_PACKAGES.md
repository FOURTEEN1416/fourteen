## 3. 并行安全矩阵

| 包对 | 可并行？ | 理由 |
|------|---------|------|
| P × C | ✅ | 两个独立外部目录，零文件交集 |
| P × V | ⚠️ **有依赖** | 论文第 4/5/7 章要引用系统"结构"与"缺口事实" → **以主控核验的缺口事实为准**，W3 若改变事实须通知主控广播 |

| V × T | ⚠️ **串行** | T 的复核依赖 V 的产物；T 第一阶段（基线+失败测试）可并行 |
| M × 任意 | ❌ | **真源文档单写**（`BOARD.md` / `TASK_PACKAGES.md` / `LOG.md` / `docs/README.md` / `AGENTS.md` / `docs/stages/**` 仅主控可写） |

```

```
