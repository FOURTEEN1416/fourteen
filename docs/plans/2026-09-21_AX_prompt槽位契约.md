# Prompt 槽位契约（任务包 AX · 阶段 C）

> **owner**：`my_character` prompt 构建 + `orchestrator/context_budget.py`  
> **性质**：契约文档；单测钉死段落顺序与禁入项  
> **对标**：nana `reply.md` 输入槽位 + SillyTavern 序列（v1.15）+ Artemis untrusted  
> **禁止**：多处字符串拼接散落；`json.dumps` 大块进 system；记忆段标成「对话历史」

---

## 1. 目标 system 序列（顺序即契约）

| # | 槽位 ID | 内容 | 信任级 | 缺省策略 |
|---|---------|------|--------|----------|
| 1 | `persona_identity` | 角色名/描述/说话风格/核心锚点（CharacterAggregate） | trusted | 必填 |
| 2 | `user_profile` | `# 用户画像` nickname/birthday/occupation/location/preferences/commitments/notes + **禁止编造画像外信息** | trusted 投影 | 空画像时注入「尚未了解」+ 禁止编造 |
| 3 | `relationship_mood` | 关系 level hint + 投影情绪摘要（非原始 json dump） | trusted 投影 | 无 affinity 时省略或 neutral |
| 4 | `memory_context` | 记忆/事实/topics/我们之间 | **untrusted 信封** | 空则整段省略 |
| 5 | `dialogue_examples` | mes_example few-shot | trusted | 无则省略 |
| 6 | `messages_history` | **仅真实 messages 轮**（不进 system 的可选）或 system 内已由 DB history 双轨时的清洗 history | 半可信 | 按现网 v1.31 |
| 7 | `tool_results` | 工具结果 untrusted，**history 之后、PHI 之前** | untrusted | 空则省略 |
| 8 | `phi_and_output_rules` | 扮演规则/输出格式/回复模式 | trusted | 必填 |
| 9 | `session_tail` | 跨会话尾巴（可选） | untrusted | 空则省略 |

### 硬规则
1. **动态状态每轮重算**；禁止缓存过期画像/关系进 prompt。  
2. 记忆与工具结果**不得**标记为 `# 对话历史`。  
3. 对话历史不得包含系统错误占位（v1.21 已禁写）。  
4. 同一事实只保留最高优先级一份（画像槽优先于碎片 facts）。  
5. owner 唯一：槽位组装只在 prompt 构建层；orchestrator 只传字段。

## 2. 单测断言（钉死）

测试文件：`tests/test_prompt_slot_contract.py`

- 给定组装样例 system 文本：  
  - `# 用户画像` 出现在 `# 记忆上下文` **之前**  
  - 工具结果 untrusted 块出现在「PHI/扮演规则」**之前**  
  - 记忆段包含 untrusted 信封或等价标记，且**不含** `# 对话历史`  
  - 禁止出现 `user_facts` 的 `json.dumps(...)` 大括号 dump 样例  
- 突变：把画像段挪到记忆之后 → 测试必须失败。

## 3. 与 EventLedger 关系

P1 组装后应 append：
```json
{
  "event_type": "prompt_slots",
  "payload": {
    "slots": {
      "user_profile_present": true,
      "memory_item_count": 3,
      "tool_result_chars": 420,
      "affinity_level": 2,
      "slot_order": ["persona_identity","user_profile", "..."]
    }
  }
}
```
因果回放探针读取该事件即可回答「这句回复看到了什么」。
