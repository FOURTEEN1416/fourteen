> **owner**：`tools/builtin/profile_agent_tools.py` + **`shisi/agent_plane/profile_projection.py`**  
> **用户裁决 2026-09-21**：**写全走 EventLedger；`user_profile` 表仅投影（可选只读物化）**  
> **对标**：nana `_merge_profile` + my-raze reinforce  
> **性质**：P0 契约；P1 工具改写必须遵守本文件

## 0. 写权威（覆盖原「表写权威」表述）

| 路径 | P0/P1 要求 |
|------|------------|
| 正确 | `write_profile_event(ledger, session_key=…)` → 返回 `project_profile` |
| 禁止 | 正则 / 工具直写 `UserProfileStore.upsert` 作为权威（仅允许 P1 在开关下物化**只读**缓存） |
| 移植 | `seed_profile_baseline` 把存量 profile 行记为基线事件 |
| 隔离 | 投影只按完整 `session_key`；无全局画像默认键 |

### 硬规则
1. **只写用户明确说过的信息**；模型回复中的信息不得写入画像。  
2. 用户否认 → **correct 事件清空**，禁止静默保留旧值。  
3. 无新信息 → **不调用工具**。  
4. 缺 `session_key` → 拒绝执行（服务端 `_meta` 注入）。  
5. extract/工具失败 → **不 append**；投影不变。

## 1. 画像字段（投影结构）

| 字段 | 类型 | 写语义 | 清空 |
|------|------|--------|------|
| nickname | str | update 非空覆盖 | correct 空串 |
| birthday | str | 同上（用户原话表述） | `clear_birthday` |
| occupation / location | str | 同上 | 空串 |
| preferences | list[str] | `preferences_add/remove`，cap 20 | 清空列表 |
| commitments | list[str] | add 去重，cap 8 | `commitments_clear` |
| notes | str | 非空覆盖；仅用户原话 | 空串 |

## 2. 长期记忆（`remember_facts`）

| 字段 | 规则 |
|------|------|
| fact | 第三人称；过 `is_injectable_fact`；~200 字 |
| category | preference / personal / work / event / commitment / relationship / general |
| topics | 可选续聊标签 |
| source | `agent` |
| confidence | agent 默认 0.85 |

### Near-dup 强化（my-raze）
- bigram ≥ **0.6** → 不插新行；access/confidence/last_seen 上调  
- P1：成功路径 **同时** `memory_write` / `memory_reinforce` 事件（账本可回放）

### 容量
- P0 不驱逐；P1 可选 capacity=20+level*10（非 D5 主动消息范围）
