# 画像 / 记忆工具 Schema 与合并规则（对端同构）

> **owner**：`tools/builtin/profile_agent_tools.py` + `shisi/memory/legacy/user_profile.py`  
> **对标**：nana `conversation._merge_profile` + `memory_extract.md`；my-raze `storeExtractedMemories`  
> **性质**：P0 契约；实施批据此钉测试与突变验红

---

## 1. 画像字段（`user_profile` 表）

| 字段 | 类型 | 写语义 | 清空 |
|------|------|--------|------|
| nickname | str | 非空覆盖 | 空串 |
| birthday | str | 非空覆盖（用户原话表述） | `clear_birthday` / 否认 |
| occupation | str | 非空覆盖 | 空串 |
| location | str | 非空覆盖 | 空串 |
| preferences | list[str] | add 去重，remove 删除，cap 20 | 空列表 |
| commitments | list[str] | add 去重，cap 8 | `commitments_clear` |
| notes | str | 非空覆盖；**仅用户原话可支撑** | 空串 |

### 硬规则
1. **只写用户明确说过的信息**；模型回复中的信息不得写入画像。  
2. 用户否认 → **必须 clear/forget**，禁止保留旧值。  
3. 无新信息 → **不调用工具**（`run_profile_sync_agent` 契约）。  
4. 缺 `session_key` → 拒绝执行（服务端 `_meta` 注入，LLM 不可决定归属）。  
5. extract/工具调用失败 → **不改库**；append `error` 事件（P1）。

## 2. 长期记忆（`remember_facts`）

| 字段 | 规则 |
|------|------|
| fact | 第三人称陈述；过 `is_injectable_fact`；max 长度对齐 MEMORY_MAX ~200 可调 |
| category | preference / personal / work / event / commitment / relationship / general |
| topics | 可选续聊标签 |
| source | `agent`（工具）或 `extract`（旁路） |
| confidence | agent 默认 0.85；extract 可更低 |

### Near-dup 强化（my-raze）
- bigram 重叠 ≥ **0.6**（双向或）→ **不插新行**  
- 更新：`access_count+=1`，`confidence=min(1.0, confidence+0.05)`，`last_seen_at=now`，可选 weight+5  
- 精确同文唯一键冲突 → 同样强化  

### 容量（P1 可选）
- `capacity = 20 + level*10`；驱逐最低 weight 且未 pinned  
- P0：**不驱逐**，只强化去重（保守）

## 3. 工具 FC Schema（摘要）

`update_user_profile` / `remember_facts` / `forget_facts` / `query_profile`  
— 已在 `profile_agent_tools.py` 注册；本契约要求实施批补：
- 每个成功路径返回 `user_key` + 变更摘要  
- `profile_correct` 事件类型用于更正  
- 禁止在工具内编造 reason 之外的「系统事实」

## 4. 验收探针映射

| 探针 | 契约点 |
|------|--------|
| 画像更正 | deny → clear；成功后投影仅含新值 |
| 双用户串台 | `user_key` 完整 session_key；查询他键为空 |
| 工具真执行 | commitments/reminders 落库，非只回文本 |
| 因果回放 | profile/memory 事件可追溯到 turn |
