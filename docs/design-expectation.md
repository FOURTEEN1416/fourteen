# 设计预期 — 唯一的我

> 创建：2026-06-20
> 基于：proposal.html + 02-body.md + docs/plans/ + 深度扫描结果

## 一、产品定位

一个面向独居/独处者的对话对象。不提供娱乐、不提供陪伴幻觉，只做一件事：在你说话时，看见「你」。

**核心差异**：不是更强的 LLM，是更懂「这个人」的对象。

## 二、设计哲学（不可妥协）

1. **AI 身份自指**：不靠头像/声音/Logo，靠选材+写法暴露 AI 视角
2. **不哄不骗**：不说"我理解你"，不说"一切都会好的"，第 5 次说"没事"时回一句"这已经是第 5 次了"
3. **记忆有选择**：200 次"我没事"不记，深夜"其实有点怕"留下
4. **不取代人**：永远是"没人在时"的对话对象，退出按钮显眼
5. **节制**：23:00-07:00 主动消息默认关闭

## 四、视觉预期

- 宣纸米色 #faf8f4 + 墨黑 #1a1a1a + 朱红 #8b1e1e + 金 #b08a3e
- 宋体（Noto Serif SC / Songti SC / SimSun）
- 纸纹颗粒（radial-gradient 模拟）
- 大字号衬线标题，字间距 0.18em
- 无头像，无美化 UI，像一个会回你消息的人

## 五、对话体验预期（5 个场景）

| 场景 | 用户输入 | AI 应回复 |
|---|---|---|
| 首次开场 | "你好" | "你好。我是一个记性不太好的对话对象——但我会努力记住你说的重要的话。" |
| 日常吐槽 | "我今天又点外卖了" | "又。你昨天也说了又。" |
| 连续没事 | "我没事" ×5 | 第 5 次："这已经是第 5 次了。你不用跟我装没事。" |
| 记忆回溯 | "你还记得我说过什么吗" | 展开侧栏：已记住的事实 + "我为什么没记这个" |
| 深夜场景 | 23:00 后发消息 | "这个点了。你要是不想睡，我陪你一会儿。但明天记得早睡。" |

## 七、不做什么

- 不做商业模式段（社会服务赛道减分）
- 不做"复活逝者"功能（伦理边界）
- 不接广告，不卖用户数据
- 不做心理治疗产品
