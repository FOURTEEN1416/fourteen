## 一、产品本质（不变的内核）

源自 persona.yaml / emotion.yaml / emotion_style_matrix.yaml 的设计基因，自 05-19 立项至今未变：

| 内核 | 载体参数 |
|------|----------|
| 情感不是标签，是状态机 | 8 级好感阶梯（陌生人→羁绊）、能量衰减/恢复、强度自然衰减 |
| 性格是可计算的 | 五维人格（warmth/playfulness/independence/jealousy/stubbornness）+ 情感→风格映射矩阵（9 情感 × warmth_delta/emoji/句长/修辞） |
| 记忆分三层 | 工作记忆 20 条 → 情景归档（20 轮触发）→ 长期 ChromaDB 向量库 |
| 陪伴是双向的 | ASE 主动消息引擎（日上限 8 条、间隔≥30min、LLM 生成、按时段分早午晚） |
| 关系要慢慢养 | 亲密度初始 0、解锁阈值 25/50/75/90（话题→表情包→语音→特殊互动） |
