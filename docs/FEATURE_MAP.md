## G. 后端核心能力（API 层，204 端点 / 21 个路由文件）

| 编号 | 能力 | 关键行为 |
|------|------|---------|
| B-01 | 微信直连 | wechat_direct/ 扫码登录、收发消息、多用户独立会话、凭证自动续期 |
| B-02 | 对话编排 | orchestrator/ 热路径 process_message（9 阶段初始化 + 会话锁）；SSE 真流式优先、伪流式降级 |
| B-03 | 情感引擎 | 8 级好感度阶梯（陌生人→羁绊）、情感状态实时更新 |

| B-05 | 主动搭话 | ASE 引擎：久未聊天/早安晚安/情绪低落触发；每日上限 + 最小间隔 + 冷却期 |
| B-06 | 语音合成 | MiMo 云（含 voiceclone/voicedesign 模型切换）/ Edge-TTS / 本地模型 fallback 链；全部端点已接 X-API-Key 认证 |

| B-09 | 安全四件套 | 内容过滤 / PII 脱敏 / 加密管理 / 提示词注入检测 |
| B-10 | 工具系统 | 天气/搜索/日历/提醒/计算器内置工具 |
