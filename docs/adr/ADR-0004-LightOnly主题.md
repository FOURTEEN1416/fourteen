# ADR-0004：仅支持 Light 主题

## 状态
Accepted

## 上下文
前端管理台的 `settingsStore` 中存在 `theme: 'dark'` 选项和相关切换逻辑，但项目中没有实现任何暗色主题 CSS。dark 选项不产生任何视觉变化。

## 决策
移除暗色主题相关代码，只保留 Light 主题。如果将来需要暗色主题，通过新的 ADR 重新引入。

## 影响
- 正面：减少约 50 行无效代码
- 正面：减少状态管理的复杂度
- 正面：样式文件更精简
- 代价：失去"未来一键加暗色"的可能性（但从未真正存在过）

## 对应 Fitness Function
FF-0005：CI 中检查代码中不包含 `theme: 'dark'` 或 `'dark'` 主题引用
