### 2.1 部署通道（大二进制提交会断流）
`git pull` 遇含大二进制的提交必现 `fetch-pack: unexpected disconnect`。改用 bundle：
```bash
git bundle create deploy.bin <服务器HEAD>..HEAD   # ⚠️ Windows 不接受 /c/... 作输出路径（静默不产出）
scp deploy.bin swu-prod:/tmp/
ssh swu-prod 'cd /opt/ai-girlfriend && git fetch /tmp/deploy.bin HEAD && git merge --ff-only FETCH_HEAD'
```
⚠️ ref 名是 **`HEAD`** 非 `main`；⚠️ `cmd | tail` 打印的是 **tail 退出码** → pull 与 deploy 分两条命令。
⚠️ 跨端同一性比 **`git hash-object`**（blob 哈希），**不比 md5**（CRLF/LF 必不同）。
⚠️ sparse-checkout（`/*` + `!/docs/`）→ B 档文档不落服务器（`ls docs/` 空即正常）。

### 2.2 改 nginx
`备份 → 写 → nginx -t → nginx -s reload`（**非 restart**）。
