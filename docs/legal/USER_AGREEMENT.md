## 2. 数据存储范围与用途（隐私声明）

### 2.1 我们存储什么

本软件在您使用过程中会在**部署服务器本地数据库**（默认 SQLite，文件位于服务端 `data/` 目录）中存储：

1. **账号信息**：邮箱、用户名、密码哈希（不可逆）、显示名称、角色权限、登录时间；
2. **聊天记录**：您与 AI 角色的对话文本及语音转写内容；
3. **记忆数据**：为维持角色长期记忆而生成的短期记忆、情景记忆、长期记忆条目；
4. **角色数据**：您创建或导入的角色卡；
5. **亲密度与情感状态**：系统计算的情感阶段、亲密度等数值；
6. **同意记录**：您同意本协议的版本号与时间戳；
7. **微信绑定关系**：若您接入微信通道，将存储您的微信标识（wxid）与角色绑定关系。

### 2.2 数据用途

上述数据**仅用于**：

- 在对话中维持角色记忆与人格一致性（让 AI"记得"你们聊过什么）；
- 计算亲密度、情感阶段，驱动情感引擎与主动搭话；
- 在管理控制台向您本人展示历史对话（仅限您自己的记录）；
- 故障排查与系统维护。

### 2.3 我们不做什么（数据红线）

1. **不出售**：本软件本身不存在向任何第三方出售、出租用户数据的行为；
2. **不共享给其他用户**：多用户之间数据严格隔离，任何用户无法查看其他用户的聊天记录、角色卡与记忆；
3. **不用于广告**：本软件不含广告跟踪 SDK；
4. **不悄悄上传**：本软件除调用您配置的 LLM / 语音服务外，不向任何外部服务器上报您的对话内容。

### 2.4 您必须知道的外部处理方（LLM 服务）

**您的对话内容会被发送给您（或运营者）自行配置的 LLM 服务提供商**（如智谱、OpenAI 等）以及语音合成服务，用于生成回复。这些服务商对数据的处理受**其各自的服务条款与隐私政策约束，不在本协议覆盖范围内**。本项目采用 BYOK（用户自带 Key）策略——LLM 服务的账号、Key 与账单由用户自理，请在配置前阅读相应服务商的隐私条款。

若您希望对话内容不离开本机，请自行配置本地模型端点。

### 2.5 数据删除与留存

- 数据存储在部署服务器本地，**删除即真正删除**：删除账号、删除角色卡或清除数据库文件后，对应聊天记录与记忆随之删除，无云端备份；
- **运营者（含自托管的您本人）负责数据备份**；本软件不含自动云备份，因未备份导致的数据丢失由运营者自行承担；
- 您可以随时要求运营者（自托管场景即您自己）删除您的全部数据。

- AI 角色不是心理医生、咨询师或任何医疗专业人员；
