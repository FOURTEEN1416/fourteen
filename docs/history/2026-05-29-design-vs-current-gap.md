# 设计稿 vs 当前前端 · 布局差距分析

> 生成日期：2026-05-29
> 对比对象：navigation-design-v10.html（v10 最终版）vs 当前 5173 前端代码
> 只比布局/功能位置，色调风格保持当前 5173

---

## 一、导航层级体系（最大差距）

### v10 设计
```
[Header] 十四 + 层级指示器
[Sidebar] ← 根据层级动态变化
  全局层 → 微信控制台 / 用户列表 / 系统设置
  用户层 → ←返回用户列表 + 角色列表
  角色层 → ←返回用户 + 角色功能tab + 角色预览卡 + 角色切换
[Content] ← 根据层级+tab渲染
[Breadcrumb] 用户管理 / 张三 / 创建角色
```

### 当前 5173
```
[Sidebar] ← 静态全局导航（微信/用户/设置）+ 路由匹配角色导航
  始终显示所有全局项
  角色层时在侧边栏底部显示 角色设置/状态中心/剧情线
  无层级切换视觉反馈
[Content] ← Route-based 内容区
[无 Breadcrumb]
```

### 差距总结
| 维度 | v10 设计 | 当前 5173 |
|------|----------|-----------|
| 侧边栏层级切换 | 三套不同内容（全局/用户/角色） | 全局+角色附加，无视觉层级区分 |
| 返回按钮 | 用户层/角色层有 ←返回 | 无，靠浏览器返回或路由 |
| 层级指示器 | Header 有层级指示（🌐全局/👤用户/🎭角色） | 无 |
| 角色预览卡 | 侧边栏角色层级有人设预览卡 | 无 |
| 面包屑 | 完整面包屑导航 | 无 |

## 二、核心页面差距

### 2.1 微信控制台

| 功能区块 | v10 设计 | 当前 5173 |
|----------|----------|-----------|
| 接入状态 | 卡片：登录状态/设备/扫码时间/消息接收/自动回复 | 横幅组件：连接状态/运行时间/今日消息/二维码 |
| 统计卡片 | 3 张：今日消息/活跃用户/在线角色 | 3 张：总连接/在线/离线 |
| 最近消息 | 消息列表（张三→十四，等） | 无最近消息 |
| 操作按钮 | 刷新二维码 / 断开连接 | 新增连接 / 编辑 / 删除（表格行操作）|
| 数据展示 | 静态卡片布局 | 表格布局（wxid/别名/状态/操作） |
| 搜索 | 无 | 有搜索框 |

### 2.2 用户列表

| 功能区块 | v10 设计 | 当前 5173 |
|----------|----------|-----------|
| 搜索 | 输入框+搜索按钮 | 有（输入框实时过滤） |
| 用户卡片 | 头像+姓名+微信号+活跃时间+角色数+状态 | 类似，但有 API 真实数据 |
| 进入用户 | 点击进入用户工作区 | 点击进入 `/users/:userId` |
| 布局 | 卡片列表 | 卡片列表，6-8 个渐变色 |

**注意：当前 UsersPage 已非 mock，有真实 API 调用！**

### 2.3 用户工作区（角色列表）

## 三、关键发现汇总

### P0 级别（功能缺失或错位）

| # | 问题 | 影响 |
|---|------|------|
| 1 | **SettingsSecurity 内容错位**—v10 设计是安全设置（API Key/内容过滤/PII等），当前是系统状态（版本/运行时间/工具列表） | tab 内容与标签不符 |
| 2 | **无三层级导航**—当前侧边栏不随层级变化，无返回按钮，无层级指示器 | 用户在大层级间导航缺乏方向感 |
| 3 | **无面包屑**—v10 设计有完整面包屑 | 用户在大层级间导航缺乏方向感 |

### P1 级别（布局差异）

| # | 问题 | 影响 |
|---|------|------|
| 4 | **侧边栏无人设预览卡**—v10 在角色层级有 persona-card | 角色层缺乏即时人设预览 |
| 5 | **微信控制台布局不同**—v10 是卡片布局，当前是表格布局 | 功能一致但视觉差异大 |
| 6 | **创建角色缺子 tab**—v10 有表单/预览/快速设置三个子 tab | 当前只有表单，缺预览和快速设置 |
| 7 | **状态中心内容薄弱**—v10 有 4 个统计卡片+情绪分布+成就+趋势 | 当前功能远不如设计丰富 |
| 8 | **角色设置中剧情时间线位置**—v10 是第 6 个 tab，当前也实现了 | ✅ 一致 |

### P2 级别（细节差异）

| # | 问题 | 影响 |
|---|------|------|
| 9 | Header 无层级指示器 | 缺少当前所在层级视觉反馈 |
| 10 | 角色预览卡在侧边栏还是内容区 | v10 在侧边栏，当前无此功能 |
| 11 | 系统设置 tab 样式（sub-tab bar vs pill 按钮组） | 视觉风格差异，功能一致 |
