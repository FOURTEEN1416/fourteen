## 🔧 附：为什么这样写（给自己看的，不用发给新窗口）

| 提示词要素 | 用意 |
|---|---|
| 指向交接文档而非复述 | 避免双真源漂移；交接文档可版本化、可 grep |
| 「先确认工作树归属」放第二步 | 并行窗口在制品是**当前最大事故源**（`git add -A` 会混批、`checkout .` 会毁灭别人成果） |
| 给出**可复制命令**而非描述 | 分块命令与判据易记错（单进程整跑会随机停住是本项目特有坑） |
| 铁律压成 8 条 | 全塞进提示词会淹没有效信息；只留「违反即事故」级 |
| 明确「先问我 3 个问题」 | 用户偏好：歧义上抛、不自动拍板；同时让新窗口第一轮就有明确产出 |
| 复述协作偏好 | 偏好跨窗口不继承，必须显式声明 |
